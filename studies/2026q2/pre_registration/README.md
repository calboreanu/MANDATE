# Protocol Archive

This directory preserves the 2026Q2 study protocol, prompts, forms, planning
documents, and deviations as they existed during the campaign.

Start with:

- `PROTOCOL_LOCK.md` for the intended decision rules and halt conditions;
- `ANALYSIS_PLAN.md` for the planned analysis;
- `PROMPTS.md` for the generation and grading prompts;
- `DEVIATION_LEDGER.md` for all 13 keyed deviation entries (not an exhaustive
  inventory of unkeyed plan-to-execution differences); and
- `DEVIATIONS.md` for the long-form deviation narratives.

This archive is evidence, not a current execution guide. Several original
planning files contain unfilled fields, prospective language, named operator
instructions, or plans that were later superseded. They are retained verbatim
because those facts define the study's methodological boundary. The campaign is
described as **protocol-governed**, not pre-registered: no externally
timestamped, fully completed pre-data registration is claimed.

For current verification instructions, use
[`../docs/REPLICATION_INSTRUCTIONS.md`](../docs/REPLICATION_INSTRUCTIONS.md).
