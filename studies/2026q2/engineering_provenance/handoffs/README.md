# Archived Operator Records

This directory contains historical task packages, run reports, and status
records produced while the 2026Q2 study was executed.

These files are preserved verbatim for process transparency. Many are
superseded, contain local host paths, or address the human and AI-assisted
operators who ran individual phases. They are not current instructions, public
API documentation, or claims made by the publication release.

The released quantitative claims do not depend on reading these records. Use
`../../docs/CLAIM_TO_DATA_MAP.md` and the machine-verification scripts under
`../../code/` for claim-level checks.
