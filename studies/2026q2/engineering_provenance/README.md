# Historical Engineering Records

This directory is retained for transparency. It is not required to verify the
paper's quantitative results and is not part of the current MANDATE software
documentation.

- `cost_log/` contains the cost ledger and its machine-readable summaries.
- `handoffs/` contains historical operator task packages, run reports, and
  status records from the evaluation campaign.

The handoff files include human-authored and AI-assisted operational text,
superseded instructions, local host paths, and intermediate status language.
They are preserved verbatim as process evidence. They must not be interpreted
as current instructions, current repository status, or publication prose.

The paper's verifiable claims map to released data and scripts through
[`../docs/CLAIM_TO_DATA_MAP.md`](../docs/CLAIM_TO_DATA_MAP.md). The successor
routing check has a separate provenance surface under
`../replication_package/v3_corrected_routing/provenance/`.
